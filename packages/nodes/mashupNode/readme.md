# 批量混剪

把同一段的备选视频放进同一个组。可以把文件拖入组内或多选上传，也可以将已有视频节点连到 A、B 等输入端口。每组至少需要一个视频，按屏幕上的组顺序各取一个片段。

例如 A、B 各放两个视频，就有四种组合。五组素材数量为 3、3、3、2、2 时有 108 种组合；填写 102 即可只导出前 102 条。调整素材前可点「预览第一条」查看拼接效果。预览通过后点「生成成片」，从第一条已保存结果继续。成片用「查看成片」切换播放，并可从视频输出端口连到其他节点。

生成在当前浏览器中执行，每条成片都会保存到工作区。需要离开时请点「暂停」，回来后可继续生成。请使用相同编码参数、尺寸和方向的 H.264 MP4 或 MOV 片段。所有片段应当都有参数一致的单条 AAC 原声音轨，或全都无声。拼接以各段画面为准，保留原声在画面中的位置。原声覆盖不到的地方补静音，超出画面的部分裁掉。工作区单个输入和成片上限是 100 MB。ZIP 下载在支持的浏览器上可直接写到所选文件。
